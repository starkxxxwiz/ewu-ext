## 🌟 Overview

**EWU Buddy** is a lightweight, modern browser extension crafted to enhance the East West University student portal experience. It streamlines course advising, simplifies routine generation with calendar exports, provides real-time seat availability heatmaps, and assists with one-click portal navigation.

---

## 🚀 Key Features

### ⚡ 1. Smart Captcha Helper
* Automatically solves mathematical security challenges on the student portal login page.
* Streamlines portal sign-in without manual calculation delays.

### 📅 2. Routine & Schedule Timetable Generator
* Instantly converts your registered courses into a visual weekly timetable grid.
* **Official EWU Calendar & Holiday Integration**: Extracts class start/end dates and recognizes university holidays so your timetable is completely accurate.
* **One-Click Multi-Format Export**:
  * **HD Image (PNG)**: Crisp, high-resolution schedule graphic for phones and laptops.
  * **Document (PDF)**: Clean printable format with course credit totals.
  * **iCalendar (`.ics`)**: Direct sync with Google Calendar, Apple Calendar, and Microsoft Outlook with automated class recurrence.
* **Smart Filter**: Automatically ignores dropped or withdrawn courses.

### 🎯 3. Online Advising Assistant & Live Seat Heatmaps
* **10-Column Advising Suite**: Enriches standard tables with real-time seats left, faculty initials, prerequisites, timings, and room allocations.
* **Color-Coded Seat Heatmap**: Visual green, amber, and red badges to instantly spot available sections during rush advising.
* **Instant Keyboard Search**: Press `Ctrl + K` to filter courses, codes, or faculty initials in real time.
* **Non-Intrusive Integration**: Enhances portal tables seamlessly without affecting native course adding or portal submissions.

### 📋 4. Interactive Course Planner (Offline & Online)
* **Drag-and-Drop Workflow**: Plan prospective semesters and test various section combinations.
* **Automated Conflict Detection**: Alerts you immediately if two chosen courses share overlapping class or lab times.
* **Schedule Preview**: View and export temporary timetable previews directly within the planner before finalizing registration.

### 📚 5. Offered Courses Catalog Enhancer
* **Sticky Table Headers**: Keep column titles fixed while scrolling through thousands of course sections.
* **Faculty Directory Links**: Quick access to instructor email links and details.
* **Filtered PDF Catalog Export**: Generate formatted PDF reports of selected departments or sections with a single click.

## 📥 How to Download & Install

### 🖥️ For PC / Desktop / Laptop (Chrome, Brave, Edge, Opera)

1. Download the latest `ewu-buddy-v1.2.zip` from the [**Releases**](https://github.com/starkxxxwiz/ewu-ext/releases) page (or download the repository ZIP and extract it).
2. Extract the ZIP archive into a folder on your computer.
3. Open your browser and go to the Extensions page:
   - **Google Chrome**: `chrome://extensions/`
   - **Brave Browser**: `brave://extensions/`
   - **Microsoft Edge**: `edge://extensions/`
4. Turn **ON** the **Developer mode** toggle (usually in the top-right corner).
5. Click **Load unpacked** (top-left) and select the extracted folder containing `manifest.json`.
6. ✨ **Done!** The EWU Buddy icon will appear in your browser toolbar.

---

### 📱 For Android Devices (Kiwi Browser, Quetta, Lemur)

1. Install **Kiwi Browser** or **Quetta Browser** from Google Play Store.
2. Download the extension ZIP file from [**Releases**](https://github.com/starkxxxwiz/ewu-ext/releases).
3. In Kiwi/Quetta, tap the **⋮ (three dots menu)** &rarr; **Extensions**.
4. Enable **Developer mode**.
5. Tap **+ (from .zip / .crx / .user.js)** and select the downloaded ZIP file.
6. ✨ **Done!** The extension is installed and ready to use.

---

## 🔄 How to Update

When a new version of EWU Buddy is released:

1. Download the new release ZIP.
2. **On PC**: Extract and replace the existing folder files, then click the **🔄 (Reload)** icon on the extension card in `chrome://extensions/`.
3. **On Android**: Remove the old extension version in the Extensions menu, then add the new ZIP.

## 🔒 Privacy & Permissions

* **100% Client-Side**: All table enhancements, routine building, conflict calculations, and PDF rendering run locally in your web browser.
* **No Credential Access**: EWU Buddy never stores, logs, or transmits student passwords or personal academic credentials.
* **Minimal Permissions**: The extension only runs on official East West University domains (`portal.ewubd.edu`, `ewubd.edu`).
